# Todo

Todo 是一款独立运行的 macOS 桌面便签，用于查看和管理飞书多维表格中的待办视图。任务保存在飞书；Todo 将选定视图投射到桌面，并可创建、编辑、完成、删除和迁移任务。

> 学习项目：Release 未使用 Apple Developer ID 签名或公证。首次运行前请核对下载来源和 SHA-256，并按下文处理 macOS 隔离提示。

## 功能

- 一张便签绑定一个飞书多维表格视图；支持便签夹切换、月历和按日导航。
- 复用飞书视图的筛选和顺序；按当前日期投射视图返回的任务。
- 新建任务，行内编辑任务内容/优先级/计划时长，勾选完成或撤销，删除任务。
- 将昨天未完成任务迁移到今天。
- 固定事项模板保存在本机，添加后立即写入当前日期，之后打开或刷新时生成当天任务。
- 番茄钟和专注累计保存在本机，不写回飞书。
- 自定义背景、透明度、中英文字体、字体颜色、粗体和斜体。
- 拖动、缩放、置顶、最小化、手动刷新；离线时可查看上次成功快照并暂存完成状态。

## 下载与首次启动

1. 从项目 GitHub 的 Releases 下载与你的 Mac 芯片相符的 ZIP 和同一版本的 SHA256SUMS.txt。
2. 在下载文件所在目录核验：

   ~~~bash
   shasum -a 256 -c SHA256SUMS.txt
   ~~~

3. 解压，将 Todo.app 拖入“应用程序”文件夹。
4. 对确认来自本项目且校验通过的应用移除下载隔离标记：

   ~~~bash
   xattr -d com.apple.quarantine /Applications/Todo.app
   ~~~

5. 从应用程序、Spotlight、Launchpad 或 Dock 启动 Todo。

如果 xattr 提示没有该属性，可直接尝试启动。SHA-256 只能帮助发现下载损坏或资产不一致，不能证明发布者身份，也不替代代码签名或公证。macOS 首次运行可能显示安全提示；首次访问钥匙串时，按系统提示允许 Todo 访问凭证。不要对来源不明或校验失败的文件移除隔离标记。

Todo 是独立应用，不需要先打开飞书，也不会随飞书启动。关闭便签页会保留应用进程，可从 Dock 重新打开；退出应用使用 Todo 菜单中的退出命令或 ⌘Q。

## 连接飞书

Todo 不内置开发者的飞书应用凭证，也不使用公网令牌服务。每位用户需要在自己有权管理的飞书组织中创建并启用自建应用。

1. 在[飞书开放平台](https://open.feishu.cn/app)创建自建应用。
2. 在应用安全设置中登记 OAuth 重定向地址：

   ~~~text
   http://127.0.0.1:43827/oauth/callback
   ~~~

3. 按 Todo 功能需要，为应用开通 Bitable 读取/写入、用户授权和离线令牌权限，并按组织要求发布或启用应用。权限名称和审批要求以开放平台实际页面为准。
4. 在 Todo 未登录空态选择连接飞书账号；在 macOS 原生凭证窗口输入自己的 App ID 和 App Secret。
5. Todo 打开系统浏览器。登录要关联的飞书账号并完成授权；成功后浏览器返回本机 Todo。
6. App ID、App Secret 和 OAuth 令牌保存在 macOS 钥匙串。更换应用凭证可从 macOS 菜单栏 Todo 菜单进入“飞书应用凭证…”并重新授权。

## 准备并绑定多维表格视图

建议视图包含以下字段：

| 用途 | 建议字段 | 类型 |
|---|---|---|
| 任务内容 | 任务内容 | 文本 |
| 日期 | 所属日期 | 日期 |
| 优先级 | 优先级 | 单选 |
| 完成情况 | 状态 | 单选，选项“未完成”“已完成” |
| 计划时长 | 计划时长 | 数字，可选，小时，按 0.5 小时递增 |

绑定时 Todo 会按标准字段名和字段类型自动识别任务内容、日期、优先级、状态；名称有差异、字段缺失或重复时，只需手动选择未识别或有歧义的字段。状态选项必须是“未完成”和“已完成”。可在“手动调整”中覆盖自动识别结果。计划时长为可选字段；唯一匹配到兼容字段时启用，否则其展示和编辑入口隐藏，其他功能仍可使用。

请在飞书视图中配置筛选和排序。Todo 使用视图 API 返回的记录及顺序，只按当前选中的日期投射记录，不复制飞书筛选条件，也不在本地重排优先级。视图必须返回 Todo 需要展示的日期范围。若当前日期没有匹配记录，便签显示“当前日期暂无待办项，请检查飞书视图筛选”。

绑定步骤：

1. 在 Todo 点击 +，选择“新建便签”。
2. 粘贴具体的多维表格视图链接。
3. 确认自动识别的字段；仅在出现未识别项或歧义时选择兼容字段，也可使用“手动调整”覆盖自动识别结果。
4. 绑定后便签显示所选日期的任务。同一飞书账号下，同一视图只能绑定一次。

## 使用 Todo

- **切换日期**：使用左右箭头逐日切换；点“今天”回到当天。日历按钮打开月历，可切换月份并选择日期。
- **新建任务**：点击 + →“新建条目”，输入任务内容和优先级；日期取当前便签选中的日期。若视图包含“计划时长”字段，可选填时长。新增任务先显示在界面，再写入飞书。
- **编辑任务**：点击任务内容、优先级或计划时长直接编辑。提交时应用会写入任务内容、优先级，以及计划时长字段可用时的计划时长；若这些值曾被其他客户端同时修改，建议刷新后再编辑。
- **完成/撤销**：点击圆圈切换状态；已完成任务进入底部折叠区，再次勾选可撤销。界面立即响应，联网时写回飞书。
- **删除任务**：在任务上右键，选择删除并确认；这会删除飞书中的记录，同时清除该任务的本机专注进度。
- **迁移到今天**：对昨天未完成任务右键选择“迁移到今天”。只修改飞书日期字段；若记录更新后不再符合视图筛选，刷新后按视图结果展示。
- **固定事项**：从 … 的便签管理打开固定事项。模板只保存在本机；添加时立即为当前选中日期创建飞书任务，之后打开或刷新便签时生成当天任务。删除模板不会删除已生成任务。
- **番茄钟**：点击任务的计时入口进入计时界面。默认工作 25 分钟、短休息 5 分钟、每 4 轮长休息 15 分钟；可自定义。专注累计保存在本机，不写回飞书；完整工作轮结束后可通过系统通知提醒。
- **个性化**：设置背景图、透明度、中英文字体、文字颜色及适用范围、粗体和斜体。支持 PNG/JPEG/WebP，背景图最大 5 MiB。
- **便签管理**：便签夹切换已绑定便签；关闭当前页会保留便签。删除便签只清理本机绑定和相关偏好、快照、专注数据，不删除飞书表格或任务。允许删除最后一张便签，之后回到空态。
- **打开源视图**：点击进度条右侧箭头。
- **最小化**：点击顶部横线按钮将窗口缩至 Dock；**置顶/刷新**可在 … 菜单中操作。需要隐藏应用时，使用 macOS 菜单栏 Todo > 隐藏 Todo。绿色/红色圆点表示飞书数据访问与写回是否可正常使用；无法正常访问或存在待处理写回时显示红色，可能由网络、授权、权限或视图读取异常导致，不代表单条记录的写入成功结果。

## 离线与本机数据

离线时 Todo 显示最近一次成功读取的快照，并允许勾选或撤销完成；这些状态暂存在本机队列，恢复联网并使用原飞书账号后尝试写回。新建、编辑、删除、迁移和固定事项写入需要联网。离线快照可能过期，飞书中的外部修改需联网刷新后读取。

本机保存账号绑定、快照、便签偏好、固定事项模板和番茄数据；OAuth 令牌及 App 凭证保存在钥匙串。登出会清除当前飞书账号的 OAuth 身份和令牌，但保留应用凭证与本机便签数据；重新登录同一账号可恢复。应用不提供一键清除全部本机数据的入口；如需彻底清除测试状态，需退出应用后按 macOS 用户数据与钥匙串的存储位置手动处理。该操作不会修改飞书云端数据。

## 从源码运行

### 环境

- macOS 13 或更新版本
- Xcode，或安装 Swift 工具链的 Xcode Command Line Tools

### SwiftPM

~~~bash
cd macOS
swift build
swift run TodoDesktop
~~~

### Xcode

在 Xcode 中打开仓库的 macOS/Package.swift，选择 TodoDesktop scheme 和 My Mac，然后运行。连接飞书仍需配置自己的自建应用凭证。

应用图标源图位于 `macOS/Sources/TodoDesktop/Resources/AppIcon.png`，macOS 多尺寸资源为同目录的 `AppIcon.icns`；Xcode/SwiftPM 运行时从资源包加载 PNG，打包脚本会把 ICNS 加入 `Todo.app`。多尺寸图稿保存在 `macOS/Assets/AppIcon.iconset/`。

### 打包

在仓库根目录执行：

~~~bash
cd macOS
./scripts/package-release.sh
~~~

脚本为当前 Mac 架构编译并生成 ZIP 与 SHA256SUMS.txt；若要提供另一个架构的包，需要在对应架构的 Mac 上构建。应用使用 ad-hoc 签名，不要求 Apple Developer Program 会员资格，也没有 Developer ID 签名或 Apple 公证。只生成本机 .app 可运行 ./scripts/package-app.sh。干净 Mac 验收步骤见[未签名 Release 检查清单](docs/release/unsigned-macos-release-checklist.md)。

## 隐私与安全

- Todo 直接从本机通过飞书 OAuth 和 Bitable OpenAPI 访问用户授权的多维表格；没有 Todo 公网令牌后端。
- 用户自己的 App Secret 与 OAuth 令牌保存在 macOS 钥匙串。不要把它们、授权码或私人任务内容提交到仓库或贴到 Issue。
- Todo 会按用户操作写入指定记录：新增、编辑、完成状态修改、删除记录和日期迁移。只绑定你有权限操作的视图。
- 未签名 Release 的 SHA-256 不证明发布者身份；请从项目 Releases 下载并核对对应版本的校验文件。

遇到问题时，请在 GitHub Issues 提供 macOS 版本、Todo 构建版本、复现步骤和错误提示。请勿附上 App Secret、token、授权码或私人任务截图。
