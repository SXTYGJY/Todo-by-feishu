# macOS 桌面壳首阶段实施计划

## 目标

将已审定的 `prototype.html` 装入轻量原生 macOS 窗口，形成可独立启动的 Todo 桌面壳。窗口支持拖动、系统原生缩放、最小尺寸、置顶切换、关闭后驻留、Dock 重开和显式退出；关闭不退出应用。

## 范围边界

- 使用 Swift、AppKit、WKWebView 和 Swift Package Manager，不引入第三方依赖。
- 本阶段不实现飞书 OAuth、Bitable API、账户数据隔离、真实任务、定时刷新、便签夹数据持久化，也不接入飞书启动联动。
- 页面仍使用原型示例数据。本阶段只通过宿主注入样式，将原型桌面预览适配到单张原生浮窗。
- 保留完整原型文件，不改动原型交互和配色。

## 实施步骤

1. 建立 Swift Package、应用入口和资源打包结构。
2. 实现 AppKit 生命周期与浮窗：默认 310×390 pt、最小 270×260 pt、普通窗口级别、置顶菜单、关闭窗口后保留进程、Dock 点击重开。
3. 使用 WKWebView 加载原型资源，并仅注入适配单窗口的 CSS；原生窗口负责移动和缩放。
4. 增加 macOS `.app` 打包脚本与最小 `Info.plist`。
5. 将 OAuth、刷新、飞书启动联动的实施状态改为“后续阶段，暂缓”；保留其需求与验收项。
6. 运行 SwiftPM 构建验证并检查最终改动。

## 交付验收

- 项目可通过 `swift build` 编译。
- `.app` 包装脚本结构完整，可生成含可执行文件和页面资源的应用包。
- 代码没有硬编码凭证、网络请求或飞书访问逻辑。
- SPEC 清楚标注本阶段已实现范围和暂缓模块。

## 风险与限制

- 历史记录：开发环境已安装 Xcode，SwiftPM 可通过完整 Xcode 工具链编译。该阶段尚未验证原生窗口运行时交互。后续发布决策已确定使用 ad-hoc Release（无 Developer ID/公证），其下载启动与 Keychain 体验由单独的干净 Mac 清单验收。
- 当前为原型壳，WKWebView 交互仍是示例逻辑；打包成功不代表飞书授权和数据读写已经实现。
